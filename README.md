# طمانينة (Tamanina) — منصة ويب احترافية ومتجاوبة

نسخة ويب كاملة من تطبيق فلاتر الأصلي: **React + TypeScript + Vite**، بتصميم طبي/مؤسسي موثوق، متجاوبة بالكامل (قائمة جانبية على الحاسوب، شريط سفلي على الجوال)، مع صفحة تعريفية (Landing)، توجيه بروابط حقيقية (React Router)، تخزين مؤقت ذكي للبيانات (React Query)، بنية جاهزة لتعدد اللغات (i18next)، ولوحة إدارة (CRUD) للفعاليات والمراكز ومنشورات المجتمع.

## التشغيل

```bash
npm install
cp .env.example .env   # ثم عدّلي القيم
npm run dev
```

## البنية العامة

```
src/
  theme/          نظام الألوان والطباعة (tokens.css) + الأنماط العامة (global.css)
  i18n/            إعداد i18next + ملفات الترجمة (ar كامل، en/fr هيكل جاهز للتوسعة)
  router/          AppRouter.tsx — كل المسارات
  layouts/         AppLayout (قائمة جانبية/شريط سفلي متجاوب) + AdminLayout
  pages/           LandingPage, LoginScreen, pages/app/*، pages/admin/*
  hooks/           useAdmin (صلاحية admin) + queries.ts (هوكات React Query)
  query/           queryClient.ts (إعداد التخزين المؤقت)
  service/         authService.ts (Firebase Auth) + apiService.ts (كل نداءات الباك اند)
  utils/           authGuard.tsx (ensureLoggedIn) + formatDate.ts
  components/      LanguageSwitcher
scripts/
  set-admin-claim.mjs   سكربت لمنح صلاحية admin لمستخدمة عبر Firebase Admin SDK
```

## المسارات (Routes)

| المسار | المحتوى |
|---|---|
| `/` | صفحة تعريفية (Landing) — تظهر أولاً على كل الأجهزة، مع زر "ادخلي إلى المنصة" |
| `/app` | الرئيسية (تدخل مباشرة كزائرة، بلا إجبار على تسجيل الدخول) |
| `/app/assistant` | المساعد الذكي — **يطلب تسجيل الدخول عند فتح الصفحة** |
| `/app/screenings` | جدول الفحوصات |
| `/app/centers` | خريطة مراكز الفحص (تُحمَّل بشكل كسول lazy-loaded لتخفيف حجم التحميل الأول) |
| `/app/community` | مجتمع الدعم — التصفح حر، **النشر يطلب تسجيل الدخول** |
| `/app/events` | الفعاليات — التصفح حر، **التسجيل في فعالية يطلب تسجيل الدخول** |
| `/admin/events` `/admin/centers` `/admin/community` | لوحة الإدارة (محمية بصلاحية admin، مُحمَّلة كسوليًا أيضًا) |

وضع الزائر محفوظ تمامًا كما في التطبيق الأصلي: التصفح حر، والدخول يُطلب فقط عند الحاجة الفعلية لميزة معينة.

## التصميم

- **الطابع**: كحلي مؤسسي (`--navy-*`) كلون أساسي للثقة، مع وردي هادئ (`--rose-*`) كإشارة لشريط التوعية وليس هوية كاملة — لا "وردي حلوى" كما في النسخة الأولى.
- **الخط**: IBM Plex Sans Arabic (خط واحد متسق عبر كل الواجهات، بدل خلط عدة خطوط).
- **الاستجابة**: `src/theme/global.css` يحوي كل شيء — قائمة جانبية تظهر تلقائيًا من 900px فأكبر، شريط سفلي على الجوال، شبكات تتكيف (`quick-grid`, `feature-grid`, `stack-grid`).
- كل الألوان متغيرات CSS في `tokens.css`، بما يسهّل تغيير الهوية لاحقًا من ملف واحد، ويدعم وضعًا داكنًا تلقائيًا حسب إعداد الجهاز.

## تعدد اللغات (i18n)

العربية (RTL) هي اللغة الافتراضية والوحيدة المكتملة الترجمة حاليًا. البنية جاهزة لإضافة أي لغة:

1. أضيفي ملف `src/i18n/locales/xx.json` بنفس مفاتيح `ar.json`.
2. أضيفيه في `src/i18n/index.ts` (السطرين `resources` و`SUPPORTED_LANGUAGES`).

الاتجاه (RTL/LTR) يتغيّر تلقائيًا مع اللغة عبر `document.documentElement.dir`، وقد أضفتُ بالفعل بعض قواعد `[dir='ltr']` في CSS للعناصر التي تحتاج انعكاسًا (الفقاعات، الحدود الملوّنة).

⚠️ ملفا `en.json`/`fr.json` حاليًا يحويان مفاتيح واجهة التنقل الأساسية فقط كمثال على البنية — أكملي بقية المفاتيح (نفس مفاتيح `ar.json`) عند رغبتك بتفعيل اللغة فعليًا.

## التخزين المؤقت (React Query)

بدل استدعاء الباك اند في كل مرة تُفتح فيها صفحة:

- **`staleTime: 5 دقائق`**: البيانات تُعتبر "طازجة" لهذه المدة، فلا يُعاد جلبها من السيرفر عند العودة لنفس الصفحة.
- **`gcTime: 30 دقيقة`**: بعد ذلك تُحذف من الذاكرة إن لم تُستخدم.
- بعد انتهاء `staleTime`، تظهر البيانات المخزّنة فورًا (بلا شاشة تحميل) ثم تُحدَّث في الخلفية تلقائيًا.
- عند أي عملية إضافة/تعديل/حذف (مثلاً حفظ موعد فحص أو حذف فعالية من لوحة الإدارة)، تُبطَل الصلاحية المؤقتة (`invalidateQueries`) لتلك البيانات تحديدًا، فتُجلب نسخة محدثة تلقائيًا.
- كل الإعدادات في `src/query/queryClient.ts` — عدّلي `staleTime`/`gcTime` من مكان واحد حسب حاجتك.

## لوحة الإدارة (Admin Dashboard)

تشمل CRUD كامل على: **الفعاليات**، **مراكز الفحص**، وحذف/إشراف على **منشورات المجتمع**.

### كيف تُمنح صلاحية admin؟

اقترحتُ الطريقة الآمنة القياسية مع Firebase: **Custom Claims** موقّعة من الباك اند، لا يمكن تزويرها من المتصفح (بخلاف مثلاً الاعتماد على قائمة إيميلات في كود الواجهة، والتي يسهل لأي شخص قراءتها من الحزمة المبنية).

خطوات التفعيل:

1. من Firebase Console → Project Settings → Service Accounts → **Generate new private key**، واحفظي الملف باسم `serviceAccountKey.json` في جذر المشروع (موجود بالفعل في `.gitignore`، لا يُرفع أبدًا).
2. `npm run set-admin -- admin@example.com`
3. على المستخدمة تسجيل الخروج ثم الدخول مجددًا (أو انتظار تحديث التوكن) لتفعيل الصلاحية.

الواجهة تتحقق من هذا الـ claim عبر `src/hooks/useAdmin.ts` (`user.getIdTokenResult().claims.admin`). رابط "لوحة الإدارة" في القائمة الجانبية لا يظهر إلا لمن يملك هذه الصلاحية، والمسار `/admin` محمي فعليًا (وليس إخفاء الرابط فقط) عبر `AdminLayout`.

**على الباك اند**: تأكدي أن كل مسارات الإدارة (`POST/PUT/DELETE` على `/events`، `/centers`، وكذلك `DELETE /community/posts/:id`) تتحقق من نفس الـ claim عبر Firebase Admin SDK (`decodedToken.admin === true`) قبل التنفيذ — حماية الواجهة وحدها غير كافية أبدًا.

### ⚠️ مسار جديد مطلوب على الباك اند

الكود الذي أرسلتِه لا يحوي مسار حذف منشورات المجتمع. أضفتُ الاستدعاء بافتراض:

```
DELETE /community/posts/:id   (Authorization: Bearer <token>, للإدارة فقط)
```

إن كان اسم المسار مختلفًا لديك، عدّلي `deleteCommunityPost` في `src/service/apiService.ts`.

## نقاط للتأكد منها على الباك اند

- **CORS**: يستخدم التطوير المحلي Vite proxy إلى `http://localhost:3000` لتجاوز CORS في المتصفح. عند نشر الواجهة بعنوان API منفصل، يجب إضافة أصل الواجهة المنشور إلى `ALLOWED_ORIGINS` في الباك اند.
- **`VITE_API_BASE_URL`**: القيمة المحلية المقترحة هي `/api`؛ يمررها Vite إلى `http://localhost:3000`. عند النشر يمكن ضبطها على عنوان API الكامل.
- **صلاحيات admin على الباك اند** كما ذكرت أعلاه.

## ملاحظات صادقة

- لم أُجرِّب المشروع فعليًا في متصفح (بيئة العمل هنا بلا واجهة رسومية)؛ فحصتُ فقط عبر `tsc --noEmit` و`vite build` الناجحين بلا أخطاء — قد تظهر تفاصيل تصميمية صغيرة تحتاج تعديلًا بسيطًا عند أول تشغيل فعلي.
- لوحة الإدارة تستخدم `window.confirm`/`window.alert` للتأكيد والتنبيهات (بسيطة وعملية)؛ يمكن استبدالها لاحقًا بنوافذ مخصصة إن رغبتِ بمزيد من الصقل البصري.
